# shinkyou_agent (診鏡 Shinkyō Agent) — Project Context

## What this project is
An AI agent that conducts a structured interview with SME managers,
assesses their Digital Transformation maturity across 5 dimensions
based on the METI DX Promotion Index (Japan, 2019), and generates
a professional PDF diagnostic report with scores, gaps, and recommendations.

## Who will see this
- Prof. ISHIGAKI Tsukasa — Tohoku University (DX/Data Analytics for SMEs)
- MEXT scholarship committee
- GitHub public portfolio viewers

## Academic Relevance
Directly supports research theme:
「中小企業における業務プロセスのAI自動化」
"AI Automation of Operational Processes in SMEs"

The agent demonstrates empirical application of DX maturity frameworks
using LLM-powered qualitative analysis combined with quantitative Likert scoring.

## Key Output
A PDF report containing:
- Overall maturity level (0–4, METI scale)
- Radar chart with scores per dimension
- LLM-generated qualitative analysis per dimension
- Gap identification and prioritized recommendations
- Benchmark comparison with Japanese SME averages (METI 2022 data)
